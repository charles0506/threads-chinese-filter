# Threads 繁簡中文過濾器與圖片縮放 (threads-chinese-filter)

竄改猴（Tampermonkey）/ 暴力猴（Violentmonkey）使用者腳本。
在 [Threads](https://www.threads.net/) 電腦網頁版上：
1. **自動隱藏非中文語言**（印尼文、英文、日文、韓文、越南文、俄文、阿拉伯文、泰文等）推薦貼文，讓動態牆只保留繁簡中文與純影音內容。
2. **滑鼠滾輪平滑縮放圖片**：點開圖片後，直接滾動滑鼠滾輪即可平滑放大縮小（以游標位置為中心直覺縮放），並支援拖曳平移與快捷鍵！

## 快速安裝

1. 先在瀏覽器安裝 [Tampermonkey 竄改猴](https://www.tampermonkey.net/) 或 [Violentmonkey 暴力猴](https://violentmonkey.github.io/)
2. 點擊此處直接安裝：
   👉 **[threads-chinese-filter.user.js](https://raw.githubusercontent.com/charles0506/threads-chinese-filter/main/threads-chinese-filter.user.js)**

腳本已設定 `@updateURL` 與 `@downloadURL`，未來推上 GitHub 更新版本時會自動提醒與同步更新。

## 主要功能

### 🖱️ 1. 滑鼠滾輪與圖片自由縮放 (New in v1.3.0)
點開貼文圖片進入燈箱彈窗（Modal）時，解鎖極致直覺的圖片檢視控制：
- **滑鼠滾輪平滑縮放**：
  - **滾輪向上**：平滑放大（每次 +20%，最高 600%）。
  - **滾輪向下**：平滑縮小。
  - **游標為中心（Zoom to Cursor）**：滾輪縮放會以滑鼠指標所指的細節為中心放大，如同地圖或繪圖軟體般順手。
  - **全螢幕 Capture 監聽**：只要燈箱開啟，即使游標在圖片邊緣或遮罩層滾動，也能 100% 穩定觸發，不會意外捲動背景網頁。
- **拖曳平移（Pan）**：
  - 圖片放大（> 100%）後，游標會變為抓手，按住滑鼠左鍵可任意拖曳查看細節。
- **雙擊快速切換**：
  - 雙擊圖片可快速切換放大/還原。
- **鍵盤快捷鍵**：
  - `+` 或 `=`（以及數字鍵盤 `+`）：放大圖片
  - `-` 或 `_`（以及數字鍵盤 `-`）：縮小圖片
  - `0`（以及數字鍵盤 `0`）：重設為 100%
  - `Escape`：若圖片處於放大狀態，按一次先重設回 100%
- **底部浮動控制列（HUD）**：
  - 畫面正下方會顯示 `[−] 100% [+] | ↺ 重設 | 🖱️ 滾輪縮放 · 拖曳平移`，支援滑鼠一鍵點擊。

---

### 🛡️ 2. 全方位外文特徵過濾
- **印尼文 / 馬來文 / 越南文 / 英文等拉丁語系**：完全不含任何 CJK 漢字且具實質拉丁字母內容者直接 100% 隱藏。
- **Threads 官方「翻譯」按鈕連動**：只要貼文旁出現官方「翻譯」/「查看翻譯」字樣，即代表官方演算法已確認為外文，直接連鎖隱藏。
- **介面雜訊排除**：自動剔除系統「2天」、「6天」相對時間與「翻譯」中文字樣，避免外文貼文因系統中文字被誤判為中文。
- **日文過濾**：日文貼文即使夾帶漢字，只要平假名/片假名累計達閥值（$\ge 2$ 個）即自動判定為日文並隱藏。
- **韓文過濾**：含韓文字母（諺文）直接隱藏。
- **其他字母系統**：包含俄文西里爾字母、阿拉伯文、泰文等外文貼文一併過濾。
- **純圖片/影片貼文**：預設保留（可透過設定選擇是否連純照片貼文也一併隱藏）。

---

### 🎛️ 3. 貼心 UI 與設定
- **右下角即時統計膠囊**：
  - 即時顯示目前已過濾的貼文數量（例：`🉐 過濾中 · 已隱藏 18 則`）。
  - **點擊膠囊**可一鍵快速切換「暫停過濾」或「恢復過濾」，不需重整頁面。
- **竄改猴選單快速設定**：
  - 支援從擴充套件選單開關「滾輪與圖片縮放」、「日文過濾」、「韓文過濾」、「無文字純影音過濾」等功能，偏好自動記憶。
- **極低資源消耗**：
  - 採用 `MutationObserver` 搭配 `requestAnimationFrame`（rAF）節流渲染，不卡頓滾動頁面。

## 運作原理

1. **動態牆過濾**：鎖定 Threads feed 的頂層卡片容器，提取內文並排除系統 UI 雜訊，判定外文或命中翻譯標記則設定 `display: none`。
2. **滾輪縮放引擎**：監聽全域 wheel 捕獲階段，結合游標座標向量運算與 CSS `transform: translate(...) scale(...)` 提供 GPU 硬體加速的順滑縮放與平移體驗。純前端呈現，不干擾網站原本邏輯。
