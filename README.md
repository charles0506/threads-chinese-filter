# Threads 繁簡中文過濾器與圖片縮放 (threads-chinese-filter)

竄改猴（Tampermonkey）/ 暴力猴（Violentmonkey）使用者腳本。
在 [Threads](https://www.threads.net/) 電腦網頁版上：
1. **自動隱藏非中文語言**（印尼文、英文、日文、韓文、越南文、俄文、阿拉伯文、泰文等）推薦貼文，讓動態牆只保留繁簡中文與純影音內容。
2. **點開圖片縮放 × 相容原生「下滑關閉」**：
   - 首頁動態牆滑動看貼文完全不干涉。
   - 點開圖片時：**滾輪往上滾放大**；原始大小**往下滾直接保留 Threads 原生「下滑關閉」手勢**！兩個功能完美共存，絕不衝突！

## 快速安裝

1. 先在瀏覽器安裝 [Tampermonkey 竄改猴](https://www.tampermonkey.net/) 或 [Violentmonkey 暴力猴](https://violentmonkey.github.io/)
2. 點擊此處直接安裝：
   👉 **[threads-chinese-filter.user.js](https://raw.githubusercontent.com/charles0506/threads-chinese-filter/main/threads-chinese-filter.user.js)**

腳本已設定 `@updateURL` 與 `@downloadURL`，未來推上 GitHub 更新版本時會自動提醒與同步更新。

## 主要功能

### 🖱️ 1. 圖片縮放與 Threads 原生手勢完美共存 (Enhanced in v1.6.0)
針對 Threads 官方燈箱「向下滾動會下滑關閉圖片」的機制，設計了智慧分流邏輯：
- **原始大小（100%）時**：
  - **滾輪向下滾**：**完全不攔截！** 讓 Threads 執行原生的「下滑關閉」手勢，看完圖片順手一滑就能關閉，保持原生習慣。
  - **滾輪向上滾**：**立即放大圖片**（每次 +25%，最高 600%）。
- **放大狀態（> 100%）時**：
  - 滾輪向下滾：平滑縮小（最低停在 100%），**在此期間全面鎖定阻斷 Threads 下滑關閉**，檢視細節絕不會意外跳出彈窗。
  - 當縮小回 100% 後，若「再次」向下滾，即可自然觸發 Threads 原生下滑關閉。
- **拖曳平移（Pan）**：
  - 圖片放大後，按住滑鼠左鍵可任意拖曳檢視細節，阻斷誤觸關閉。
- **雙擊快速切換**：
  - 雙擊圖片可快速切換放大/還原。
- **鍵盤快捷鍵**：
  - `+` 或 `=`（以及數字鍵盤 `+`）：放大圖片
  - `-` 或 `_`（以及數字鍵盤 `-`）：縮小圖片
  - `0`（以及數字鍵盤 `0`）：重設為 100%
  - `Escape`：若圖片處於放大狀態，按一次先重設回 100%

### 🛡️ 2. 全方位外文特徵過濾
- **印尼文 / 馬來文 / 越南文 / 英文等拉丁語系**：完全不含任何 CJK 漢字且具實質拉丁字母內容者直接 100% 隱藏。
- **Threads 官方「翻譯」按鈕連動**：只要貼文旁出現官方「翻譯」/「查看翻譯」字樣，即代表官方演算法已確認為外文，直接連鎖隱藏。
- **介面雜訊排除**：自動剔除系統「2天」、「6天」相對時間與「翻譯」中文字樣，避免外文貼文因系統中文字被誤判為中文。
- **日文過濾**：假名達 2 個以上，且假名數超過漢字數的 30% 才判定為日文並隱藏；中文貼文夾雜少量日文會保留。
- **韓文過濾**：諺文字數超過漢字數的 50% 才判定為韓文並隱藏；中文貼文夾雜少量韓文會保留。
- **其他字母系統**：包含俄文西里爾字母、阿拉伯文、泰文等外文貼文一併過濾。
- **圖片/影片貼文**：貼文帶圖片或影片（作者大頭貼不算）且說明文字不超過 20 個字母（例：`Good morning ☀️`、`#sunset 🌅`），預設**保留**；說明是整句外文的照常過濾。泰文、日文、韓文、俄文、阿拉伯文等非拉丁文字的說明，再短也照常過濾。可從選單改回一律照常過濾。
- **翻譯按鈕誤判保護**：Threads 有時會在中文貼文旁也放「翻譯」按鈕；漢字數不少於英文單字數時視為中文貼文，不因翻譯按鈕被隱藏。
- **地區標籤剔除**：判斷語言前先拿掉帳號地區標籤（例：`🇲🇽 墨西哥`），避免外文貼文因標籤是中文字而被當成中文。
- **純圖片/影片貼文**：關閉上一項時，完全沒文字的貼文仍預設保留（可透過設定選擇隱藏）。內文只有數字、標點、emoji（例：`2026`、`10/27`、`😂😂`）也視同純圖片貼文。
- **詐騙帳號提醒**：貼文上出現帳號地區標籤且為「非台灣 + `[新帳號]`」（例：`🇲🇾 馬來西亞[新帳號]`），不論內文是否為中文：
  - 預設 **紅框提醒**：貼文加紅框，頂端顯示「⚠️ 疑似詐騙帳號」警示條。
  - 選單可切換為 **直接隱藏**（列入被過濾清單，原因「詐騙帳號」）或 **不處理**。
  - 需搭配會在貼文上顯示帳號地區／新帳號標籤的擴充功能或腳本；本腳本只讀標籤文字，不自行查詢帳號資料。

### 🚫 2-0. 不喜歡 / 封鎖作者 / 關鍵字
- 每則貼文底部都有「🚫 不喜歡」按鈕，按下後可選：
  - **隱藏這則**：只藏這一則，重整後仍隱藏。
  - **封鎖 @作者**：這個帳號的貼文全部隱藏。
  - **加關鍵字…**：內文含此字的貼文全部隱藏（不分大小寫）；可先反白選取文字再按，會自動帶入。
- 封鎖名單顯示在「被過濾的貼文」清單頂端，點 ✕ 解除，被藏的貼文會立即放回。
- 清單中「不喜歡」的貼文按「還原顯示」會一併從隱藏名單移除。

### 🧠 2-0-1. 喜好 AI：學你不喜歡什麼（僅 Chrome）
- 用 Chrome 內建的 Gemini Nano（Prompt API），模型在本機執行、免費、不上傳貼文；第一次需下載約 2～4 GB，電腦硬體不足時 Chrome 會回報不支援。
- 你按「🚫 不喜歡」→「隱藏這則」或「封鎖作者」時，那則內文會記成反例（最多 20 則）。累積 3 則後開始運作，自動隱藏內容相似的貼文，清單原因標「AI：像你不喜歡的」。
- AI 藏錯了就在清單按「還原顯示」，那則會記成正例（最多 10 則），之後不再藏類似貼文。
- **怎麼知道有沒有在運作**：
  - 右下角膠囊出現 🧠（語言偵測 AI 是 🤖），下載模型時顯示 ⏳。
  - 點膠囊，清單頂端顯示狀態與統計，例：「運作中・已學 5 則不喜歡・本頁判斷 32 則、藏 3 則」。
  - Chrome 網址列輸入 `chrome://on-device-internals` 可看模型下載與執行狀態。
- 竄改猴選單可關閉，或清除學到的例子。

### 🤖 2-1. AI 語言偵測（僅 Chrome）
- 用 Chrome 內建的 `LanguageDetector` AI（Chrome 138 以上），模型在本機執行、免費、不上傳貼文。
- 規則放行的貼文再交給 AI 複查：AI 判定不是中文且信心度 ≥ 70% 才隱藏，清單原因標「AI：英文」「AI：西班牙文」等。
- 不送 AI 的貼文：字母少於 8 個、短說明的圖片貼文、漢字數 ≥ 4 且不少於英文單字數的中文貼文。
- 第一次使用要下載模型，Chrome 規定需使用者操作觸發：點一下頁面任意處即開始下載。
- 狀態顯示在「被過濾的貼文」清單頂端；Firefox 等不支援的瀏覽器會顯示「不支援」並自動略過。
- 可從竄改猴選單「🤖 AI 語言偵測」關閉。

### ⬇️ 3. 圖片/影片下載
- 有圖片或影片的貼文底部會出現「⬇ 下載圖片/影片」按鈕，一鍵下載整則貼文的所有媒體。
- 圖片自動挑 `srcset` 裡解析度最高的版本；影片下載原始 mp4。
- 檔名格式：`threads_<作者>_<貼文ID>_<序號>.<副檔名>`。
- 透過竄改猴 `GM_download` 下載；若被擋（例如副檔名不在竄改猴下載白名單），會改開新分頁讓你手動另存。
- 影片若是 `blob:` 串流格式則無法下載，按鈕會提示。

### 🎛️ 4. 貼心 UI 與設定
- **右下角即時統計膠囊**：
  - 即時顯示目前已過濾的貼文數量（例：`🉐 過濾中 · 已隱藏 18 則`）。
  - **點擊膠囊**展開「被過濾的貼文」清單：列出作者、內文摘要與過濾原因（詐騙帳號／翻譯按鈕／日文／韓文／其他文字／無中文／純影音／AI：語言名／AI：像你不喜歡的／不喜歡／封鎖作者／關鍵字）。
  - 清單每則可按「還原顯示」把貼文放回動態牆（之後不再隱藏），或「開啟貼文」另開分頁查看。
  - 清單右上角可一鍵切換「暫停過濾」或「恢復過濾」，不需重整頁面。
- **竄改猴選單快速設定**：
  - 支援從擴充套件選單開關「點開圖片縮放」、「日文過濾」、「韓文過濾」、「無文字純影音過濾」等功能，偏好自動記憶。
- **極低資源消耗**：
  - 採用 `MutationObserver` 搭配 `requestAnimationFrame`（rAF）節流渲染，不卡頓滾動頁面。
